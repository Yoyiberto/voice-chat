TTS LAB / OUTPUT VOICES

Prueba voces de salida.
Gratis y para español.

Compara voces del sistema (Microsoft/Google), voces neurales de Microsoft Edge vía tu servidor, y Piper local en el navegador. Todas gratuitas.

100%

01 / SISTEMA (Web Speech)

Voces ya instaladas

—

Son las voces que expone el navegador y que usa la app principal por defecto (es-ES). El 100% ya es el máximo de Web Speech: el navegador no permite amplificar esta salida por encima de 1. Si suena bajo, sube el volumen multimedia del sistema o usa Edge/Piper, que sí admiten ganancia.

02 / MICROSOFT EDGE (neural)

Vía el servidor

—

Voces neurales de alta calidad (gratis, sin API key). El audio se genera en tu servidor y aquí solo se reproduce, así que funciona en móvil. Requiere red.

03 / PIPER (local offline)

En el navegador

—

Neural que corre 100% local (WASM). El modelo incluido está en public/piper/ y se carga al pulsar la voz local. Para el móvil, sirve esta misma app y no necesita descargarlo otra vez; también puedes cargar un modelo y su config manualmente.
